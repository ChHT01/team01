# Инструкция для участника

Это короткая шпаргалка: как запускать свой Python-код и пользоваться библиотекой робота.

## Что уже установлено

После установки на компьютере есть:

- **uv** — программа, через которую запускают Python-скрипты в этом проекте
- **motion-core-API** — библиотека для управления роботом (пакет `motion`)
- **окружение `.venv`** — отдельная «коробка» с нужными библиотеками (её трогать не нужно)

Работайте **в папке этого проекта** (там, где лежат `pyproject.toml` и ваши скрипты).

## Как запустить свой скрипт

1. Откройте терминал в папке проекта.
2. Создайте файл, например `main.py`.
3. Запустите его так:

```bash
uv run python main.py
```

или короче:

```bash
uv run main.py
```

**Важно:** не запускайте просто `python main.py`. Так можно «не увидеть» установленные библиотеки. Всегда используйте `uv run`.

## Как подключить библиотеку робота в коде

В начале файла напишите:

```python
import motion
```

Дальше используйте функции и классы из этой библиотеки по заданию / примерам от преподавателя.

Если Python пишет `ModuleNotFoundError: No module named 'motion'` — скорее всего, вы запустили файл не через `uv run` или не из папки проекта.

## Полезные команды uv

| Что нужно | Команда |
|-----------|---------|
| Запустить скрипт | `uv run python имя_файла.py` |
| Проверить, что Python видит пакеты | `uv run python -c "import motion; print('ok')"` |
| Посмотреть список установленных пакетов | `uv pip list` |

## Чего делать не надо

- Не удаляйте папку `.venv` и файл `pyproject.toml`
- Не кладите в git большие файлы: фото, видео, веса нейросетей (`.pt`, `.pth`), архивы — они уже в `.gitignore`
- Не переустанавливайте всё заново без просьбы преподавателя

## Если что-то сломалось

1. Убедитесь, что терминал открыт **в папке проекта**.
2. Проверьте запуск: `uv run python -c "import motion; print('ok')"`.
3. Если снова ошибка — позовите преподавателя или волонтёра. Не удаляйте файлы «наугад».
