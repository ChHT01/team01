# Это шаблон для создания репозиториев под ЧВТ
Этот репозиторий нужно закачать на компьютеры участников, за которыми они будут сидеть локально.
## Алгоритм установки программного обесепчения на компьютеры участников
0. **Шагом 0 нужно проверить есть ли токен доступа к motionc-core-API или tar-архив этого пакета**
1. Затем необходимо выполнить скрипт установки build.sh  
    ```
    build.sh установит пакетный менеджер uv, создаст git-репозиторий, напишет .gitignore и pyproject.toml
    ```
    **ВАЖНО** - под конец исполнения скрипта скрипта он попросит  добавить ссылку на удалённый git-репозиторий. без добавления ссылки скрипт установки не завершится. Если по какой-то причине ссылки на удалённый репозиторий ещё нет, то можно тупо нажать enter и затем уже в ручную сделать 
    ```bash
    git remote add origin https://repo.git 
    ```
2. В файле содержится ещё `participant.md`, в котором содержится инструкция для учатсников о том как писать и запускать код. 
3. При успешном исполнении скрипта НУЖНО удалить motion-core-API-0.2.tar.gz и build.sh
4. Школьники рано или поздно всё сломают, так что держите оригинал этого репозитория при себе. ЧТобы скрипт build.sh заработал, желательно, но необязательно иметь рядом с ним motion-core-API-0.1.2.tar.gz и pyrpoject.toml
5. При желании добавьте школьникам пару примеров в папке examples
5. после установки всего можете с чистой совесвтью и потрёпанными нервами удалить build.sh и если нервов осталось критически мало, то можно также удалить и examples
